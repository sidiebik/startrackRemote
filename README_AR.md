# STAR TRACK REMOTE PRO

مشروع Android أولي لهاتف يدعم الأشعة تحت الحمراء، مستهدف لتلفزيون STAR TRACK موديل ST-43D-AZ2000 والريموت الظاهر عليه رقم AD1783.

## الوظائف
واجهة أزرار للطاقة، الأرقام، الصوت، القنوات، الاتجاهات، ENTER، MENU، SOURCE، BACK، EXIT وبعض أزرار الاختصارات.

## تحذير التوافق
الأكواد في هذا المشروع تجريبية عامة بصيغة NEC وليست مستخرجة من الريموت AD1783 ولا توجد لدينا إشارة مؤكدة أنها تطابق ST-43D-AZ2000. ظهور "تم اكتشاف مرسل IR" يعني أن Android تعرّف على باعث IR فقط، ولا يثبت توافق الأكواد مع التلفزيون.

## البناء على الهاتف
افتح المشروع في بيئة Android IDE متوافقة مع Gradle وAndroid SDK، ثم نفّذ مهمة assembleDebug. ينتج APK تجريبي داخل app/build/outputs/apk/debug/.

## المتطلبات
- Android API 23 أو أحدث.
- جهاز فعلي به Consumer IR emitter متاح للنظام.
- لا يحتاج التطبيق إلى الإنترنت لإرسال الأشعة.
